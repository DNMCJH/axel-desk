# Axel Desk

[English](README.md) | [简体中文](README_CN.md)

Obsidian 的本地个人桌面：把待办、常用笔记、随手记录和图片放在手边，不需要账户，不接入远程服务，不在打开首页时调用模型。

当前源码版本：**0.2.0-rc.7**，仍是候选版。源码更新与 GitHub Release 分开管理。

## 主要功能

- **个人待办**：手动添加、编辑、完成、重新打开，以及移除后恢复；内容保存在当前 Vault 的插件设置中。
- **含待办的文件**：按文件汇总未完成复选框，显示完整文件名、Vault 相对路径和数量。点击可定位到第一条未完成项。历史副本和模板默认排除；数量不代表今天必须做。
- **自主整理**：不需要的文件条目可移入 Desk 回收站，不删除源文件、不修改原文复选框；即使源文件后来有变化，也要主动恢复才重新显示。回收项默认 30 天后归档，可在设置中调整。
- **顶部图片轮播**：位于页头下方，支持上一张、下一张、圆点选图和暂停；图片切换仅更新横幅，不重绘便签。也可选择多图网格模式。
- **便签与固定笔记**：便签随手保存，按需转为笔记；固定笔记可直接编辑。编辑便签和输入个人待办时，后台全页刷新会延后，避免打断光标和中文输入。
- **通用与计算机学习模板**：支持台历、近期笔记、代码块语言分布、概念债、回顾队列等可选卡片。卡片可关闭、调整顺序；单图轮播固定在顶部。
- **真实入口**：仅在已配置且实际存在的目录上显示对应快捷入口，不默认生成 Git 或 terminal 插件按钮。
- **分栏适配**：按 Obsidian 实际面板宽度调整布局，而非只按窗口宽度判断。

## 安装或更新

1. 从 Releases 获取对应版本的安装包，或按下方命令构建当前源码。
2. 解压到当前 Vault 的插件目录，确认最终路径为 `.obsidian/plugins/axel-desk/main.js`。
3. 在 Obsidian 的第三方插件设置中启用 Axel Desk。
4. 更新已有安装时替换插件文件，保留自己的 `data.json`；然后关闭再开启 Axel Desk 加载新版本。

可选目录默认留空，按自己的笔记结构配置。不要复制其他人的设置文件。

## 图片与权限

在设置中指定当前 Vault 内的本地图片目录。插件本身不下载图片，安装包也不包含个人参考图。请使用自己的图片或有权使用的素材。

## 本地数据边界

Desk 回收、归档仅影响桌面显示状态，不删除源文件。便签转为笔记、固定笔记编辑等明确的编辑操作会写入相应笔记。插件不读取 Vault 之外的项目 Git 历史，也不需要额外的终端插件。

## 开发与验证

```bash
npm ci
npm run build
npm test
npm run pack
```

打包产物位于 `dist/`。浏览器视觉验证脚本为 `tools/preview-banner.js` 与 `tools/preview-task-board.js`，需要另外提供本机 Playwright 环境；前者通过 `DESK_BANNER_IMAGES` 接收本地测试图片目录，支持用 `DESK_HOST_STYLES` 加载宿主样式以检查主题兼容性。
